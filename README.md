# ATALAYA

Retrato lingüístico (*language portrait*) para Android. Grupo de investigación linGAP, Departamento de Lengua Española, Universidad de Salamanca.

**[Descargar ATALAYA.apk](https://github.com/emmachados/atalaya/releases/latest/download/ATALAYA.apk)**

Solo Android (7.0 o posterior). No disponible para iPhone (iOS).

Versión 1.7.3. SHA-256 del APK: `49e4c1d681062dd90dc2fe846256a23c7ea903f8c99699bfa8a7ad19863ed8ed`

## Instalación

1. Abra el enlace de descarga en el teléfono Android.
2. Abra el archivo descargado. Android pedirá autorizar la instalación desde el navegador o el gestor de archivos; acepte y vuelva a abrir el archivo.
3. La primera transcripción descarga el modelo Whisper small (unos 500 MB) desde Hugging Face. Las siguientes funcionan sin conexión y el audio no sale del dispositivo.

## English

Language portrait app for Android. Android only (7.0 or later); not available for iPhone (iOS). Open the download link on the phone, open the downloaded file and allow installation from that source when Android asks. The first transcription downloads the Whisper small model (about 500 MB); after that, transcription runs offline on the device.
